# Instructions for coding agents

This repo is a guide and toolkit for building reinforcement-learning environments and graded tasks. Before building any environment or task, read `skills/rl-env-playbook/SKILL.md` and follow it. It routes to:
- `skills/rl-clone-tickets/SKILL.md` for finishing an app or app clone (tickets)
- `skills/rl-coding-task/SKILL.md` for coding tasks with hidden tests
- `skills/rl-computer-use-task/SKILL.md` for computer-use tasks with a state verifier
Read a skill's `references/` files when its SKILL.md points to them. Scripts live in each skill's `scripts/` folder.
