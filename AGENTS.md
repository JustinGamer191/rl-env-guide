# Instructions for coding agents

This repo holds the playbook for the Frist RL hackathon. Before doing any Frist work, read `skills/frist-hackathon-playbook/SKILL.md` and follow it. It routes to:
- `skills/frist-clone-tickets/SKILL.md` for clone tickets
- `skills/frist-coding-task/SKILL.md` for coding tasks
- `skills/frist-computer-use-task/SKILL.md` for computer-use tasks
Read a skill's `references/` files when its SKILL.md points to them. Scripts live in each skill's `scripts/` folder.
